# WhiteSoft

**在浏览器里运行的本地白板，可以导入 PDF，读写 Microsoft Whiteboard 的 `.note` 文件。**

WhiteSoft 是一个复刻 Microsoft Whiteboard Windows 本地版的本地应用。界面是纯前端的 Canvas
应用，由本机一个零运行时依赖的 Node 进程把页面发给浏览器。白板的读写全部由浏览器对着你自己的
文件完成：文件从磁盘打开，保存时写回原文件。没有工作区、没有副本、没有上传，全程离线。

![WhiteSoft 界面][shot]

> **English** — WhiteSoft is an offline whiteboard that runs in your browser and speaks the
> `.note` format of Microsoft Whiteboard, with PDF import, LaTeX, curve shapes, a
> full-spectrum colour picker and a small Go desktop app. Every board is opened and saved by
> the browser against your own files, so nothing is uploaded and no copy is kept.

## 亮点

- **导入 PDF** —— n 页的 PDF 变成 n 张画纸，每张画纸以对应的 PDF 页为背景，
  右下角的页码输入框可以直接跳到任意一页。
- **打开与保存 `.note`** —— 直接读取 Microsoft Whiteboard 本地版保存的 `.note` 文件，
  忠实还原每张画纸上的墨迹、荧光笔、直线、矩形、椭圆、箭头、折线、图片、文本与 PDF 背景；
  改完存回 `.note`，得到的文件可以直接用 Microsoft Whiteboard 打开。放大画纸时会按当前比例
  重新光栅化 PDF，100% 到 800% 都能保持清晰；万一某个浏览器画不出那么大的画布，
  会自动退到它能画出的最高分辨率，而不是把整页变成一张白纸。
- **数学公式** —— 文本框和便签里可以直接写 LaTeX，由内置的 MathJax 渲染成真正的数学排版，
  离线可用。
- **全色系取色器** —— 所有需要选颜色的地方都是同一个控件：预设色板加可展开的全色系调色盘，
  支持饱和度与明度、色相、不透明度、十六进制输入与键盘微调。
- **曲线形状与任意画拟合** —— 抛物线、双曲线、正弦波、三次曲线一次拖出；
  随手画一条线也能拟合成光滑的高次曲线。
- **桌面端** —— `desktop/` 里是一个轻量 Go 程序，把同一个界面做成桌面应用，
  另带一个终端管理器，可以在终端里浏览与检索 `.note`。
- **非破坏性保存** —— 写入 `.note` 时源文件里的条目原样保留，包括当前没有任何画纸引用的图片；
  写入先落临时文件再替换，中途失败不会破坏原文件。
- **一键压缩** —— 删掉文件里没有任何对象引用的图片与文档，把未压缩存放的条目重新压缩，
  其余条目逐字节保留；压缩前先列出会删什么、能省多少空间。
- **文件就是文件** —— 用系统文件对话框打开，`Ctrl+S` 原地写回；最近使用的列表记的是文件位置，
  不是副本，服务端不接触任何白板。

## 快速开始

### 环境要求

| 项目 | 要求 |
|---|---|
| **Node.js** | **18 或更高**。服务端只用 Node 内置模块，运行时不需要 `npm install` |
| **浏览器** | 桌面版 Chrome / Edge / Firefox，需要 Canvas 2D、`Path2D` 与 ES Module |
| **系统** | Linux / macOS / Windows。启动脚本是 bash，Windows 上直接运行 `node server.mjs` |

### 启动

```bash
git clone https://github.com/cutx64/WhiteSoft.git
cd WhiteSoft
./whitesoft.sh
```

脚本会检查 Node 版本、确认端口可用，然后启动服务并打印界面地址；
用浏览器打开 **http://127.0.0.1:8787/** 即可，加 `--open` 会自动打开浏览器。

服务端只负责把界面发给浏览器，白板的读写全部在浏览器里完成，所以不需要指定任何目录。

常用参数：

| 参数 | 说明 |
|---|---|
| `-p, --port <n>` | 监听端口，默认 `8787`，也可以用环境变量 `PORT` |
| `-H, --host <addr>` | 监听地址，默认 `127.0.0.1`，只有本机能访问；改成 `0.0.0.0` 会暴露到局域网 |
| `--open` | 启动后自动打开默认浏览器 |
| `--auto-port` | 端口被占用时自动顺延，最多试 50 个 |
| `-h, --help` | 显示帮助 |

也可以绕过脚本直接启动服务：

```bash
node server.mjs --port 8787 --host 127.0.0.1
```

PDF 渲染与 ZIP 打包所需的第三方库都已放在 `public/vendor/`，离线可用。

### 第一次使用

1. 点标题栏的 **导入 PDF**，或者把 PDF 拖进窗口，生成 n 张画纸，每页以 PDF 页为背景。
2. 用工具栏在画纸上批注；右下角的页码框可以跳到任意画纸。
3. `Ctrl+S` 第一次会让你选一个保存位置，写出 `.note`，之后 `Ctrl+S` 就原地覆盖这个文件。
   得到的 `.note` 可以直接用 Microsoft Whiteboard 打开。
4. 想接着改本机已有的 `.note`，点 **打开** 里的 **从本地文件选择**；
   下次可以从 **最近使用的文件** 里直接再打开。

## 桌面端

`desktop/` 是一个轻量 Go 程序，给同一个界面套上桌面体验。它不重写白板，只负责找到
`server.mjs`、挑一个空闲端口、等它就绪后打开窗口，退出时把子进程一起收走。

```bash
cd desktop
go build -o whitesoft .          # 需要 Go 1.24 或更高，运行时需要 Node.js 18 或更高
./whitesoft                      # 桌面端：启动服务并打开浏览器
./whitesoft --port 9000          # 指定端口，默认自动挑一个空闲端口
./whitesoft --no-open            # 只启动服务，不打开浏览器
./whitesoft tui                  # 终端管理器
```

| 选项 | 说明 |
|---|---|
| `--port <n>` | 端口，默认 `8787`，与 `whitesoft.sh` 一致；被占用时自动顺延，指定后严格使用 |
| `--host <addr>` | 监听地址，默认 `127.0.0.1` |
| `--server <path>` | 手动指定 `server.mjs`，默认从可执行文件所在目录向上查找 |
| `--node <path>` | 手动指定 node 可执行文件 |
| `--no-open` | 只启动服务，不打开浏览器 |
| `--root <dir>` | 仅 `tui` 子命令使用，指定要浏览的白板目录 |

### 终端管理器

`./whitesoft tui` 打开一个 go-tui 写的终端界面，只读地查看白板库：

- 左栏列出目录里的 `.note`，显示页数、图片数、是否内嵌 PDF 与文件大小；
- 选中后按 `enter` 在后台解析页面，右栏列出每页的元素、墨迹点与图片统计；
- 选中画纸会显示它的文字与 LaTeX 源码预览，按 `a` 展开全部文字；
- `/` 既能过滤白板名，也能按内容过滤画纸；`s` 启停服务，`o` 切到网页端编辑。

按键：`j/k` 或 `↑↓` 移动 · `tab` 切换栏位 · `enter` 载入或打开 · `o` 浏览器打开 ·
`s` 启停服务 · `/` 搜索 · `a` 展开文字 · `r` 重新扫描 · `q` 退出。

终端里没有画布，无法绘图，所以管理器只负责浏览、检索与统计，编辑仍在网页端完成。
Go 侧对 `.note` 永远只读，写入只有一份实现，就是浏览器里的 `zipwrite.js`。

## 功能

### 墨迹与笔

- **3 支可分别自定义的笔**，用 `Alt+1`、`Alt+2`、`Alt+3` 切换：每支各有 15 种颜色与 17 种
  渐变笔，包含 Whiteboard 的彩虹与极光，以及 matplotlib 的 viridis、plasma、inferno、magma、
  cividis、turbo、jet、coolwarm、spring、summer、autumn、winter、ocean、terrain、twilight；
  粗细 1–20 连续可调，另有不透明度与无箭头、单箭头、双箭头三种笔尖。
  换颜色或换渐变后，面板里笔 1、笔 2、笔 3 前面的小圆点会立刻跟着变。
- **荧光笔**：15 色、半透明、粗细 8–60，带「直线绘制」开关，开启后像直线工具一样拉出笔直的
  高亮；画得几乎水平时会自动吸附成**严格水平**，适合划线，明显倾斜的角度照原样保留，
  按住 `Shift` 可以强制保留手画的角度。**粗细是页面上的距离，不是屏幕像素**：同一个数字在任何比例下画出来的高亮都一样宽，
  画布放大两倍再画 24，得到的仍然是 24，只是它在屏幕上看过去粗了一倍，而面板里始终显示 24。
  直线高亮在**框选放大缩小时宽度不变**：用 30 号画出的那条高亮，框选放大后仍然是 30，
  只是变得更长；**页面比例放大缩小时，它跟着页面一起变粗变细**。自由手绘的高亮与普通笔迹
  仍按原来的比例缩放。
- **激光笔**不落墨并自动淡出；**橡皮擦**按整笔擦除，划过笔画就删掉那一笔，
  但不会碰图片、便签与文本框，这三样选中后按 `Delete` 删除；按住 `Shift` 绘制可以约束成
  直线、正方形或正圆。

### 高亮端点

凡是直线高亮，包括两点高亮与从旧文件里读到的完全共线高亮，都画成跑道形：矩形高亮带配两端半圆。
这类直带在缩放时保持自己的宽度，放大只改变长度；自由手绘的弯曲高亮仍是平头，并按比例缩放。
打开原版 `.note` 时，用直线绘制划出的高亮也会以半圆端点渲染。不想要这个效果，
可以在设置里关掉「高亮直线显示半圆端点」。

### 直尺

点工具栏的尺子图标或按 `R` 显示。直尺悬在画布之上，任何工具下都能直接抓住：拖尺身移动，
拖右端手柄旋转，悬停时滚滚轮微调角度；沿尺边画线会自动吸附成直线，
按住 `Shift` 可以吸附到 15° 的整数倍。

### 对象

形状、文本框、便签、表格、图片与反应都可以直接插入画布。形状包含正方形、圆、三角形、五边形、
六边形、五角星、块状箭头、平行四边形、菱形与圆角矩形，以及虚线、直线、单箭头与双箭头，
并且可以填充；便签有 12 种颜色；图片可以插入、粘贴、缩放与旋转；反应有 8 个 emoji。

### 曲线形状与任意画拟合

形状面板的第二栏是曲线，拖出一个范围就得到铺满该范围的曲线：

| 曲线 | 形状 |
|---|---|
| **抛物线** | 顶点在下边缘，两端伸到上角 |
| **双曲线** | 左右两条分支，各自从下到上，停在中线两侧 |
| **正弦波** | 跨两个完整周期，振幅为高度的 80% |
| **三次曲线** | 向右单调上升的 S 形 |

曲线同样支持虚线与填充，填充会把曲线与基线收口成闭合图形。曲线按普通折线保存，
这是 Microsoft Whiteboard 本来就有的元素类型，所以文件在原版里照样能打开；
双曲线是两条分支两个元素，但一次绘制只记一步撤销。

**任意画拟合**：形状面板的最后一格，或者选中墨迹后用「更多」里的「曲线拟合所选墨迹」。
随手画一条线，松手后会换成一条光滑的高次曲线，竖线、对勾、连笔都能拟合，而不只是函数图像；
拟合结果与原笔迹偏差过大时宁可不换，保留原来的墨迹。

### 全色系取色器

凡是能选颜色的地方，包括笔、荧光笔、形状边框、形状填充、文本、便签、画布背景与所选操作栏，
都是同一个控件：预设色板加「🎨 自定义颜色」。展开后是一个全色系调色盘：

- **饱和度与明度方块**：拖动取色，方向键可以微调，按住 `Shift` 加大步长；
- **色相条**：0–359°；
- **不透明度条**：只在透明度没有被别的滑块管着的地方出现；
- **十六进制输入**：直接输入 `#RRGGBB`；
- **实时预览**：拖动时画布或对象立刻跟着变，松手才记一步撤销。

颜色在文件里一律存成 `#AARRGGBB`，所以自定义颜色与预设颜色一样会随白板保存，
Microsoft Whiteboard 打开也是同一个颜色。

### 便签样式

便签默认是圆角的，颜色、透明度与圆角大小都可以单独调整：

- **颜色**：12 色便签色板；换颜色只改色相，不会把便签的透明度改回不透明。
- **透明度**：10% 到 100%，写在便签颜色的 `#AARRGGBB` 里，随文件一起保存。
- **圆角**：0% 到 50%，按便签短边的比例计算，缩放便签时圆角跟着变。
- 工具栏的便签工具可以打开这个面板，选中便签后点操作栏的便签样式按钮也可以；
  选中多张便签时一次改全部，面板里的设置同时会成为新建便签的默认样式。

### 数学公式

文本框和便签里可以直接写 LaTeX，画布上渲染成真正的数学排版：

| 写法 | 效果 |
|---|---|
| `$x^2+y^2$` | 行内公式，与中英文混排 |
| `$$…$$` | 独立公式，自动独占一行 |
| `\$9.99` | 转义，按字面量显示 `$9.99` |

渲染交给内置的 MathJax，离线可用，不请求 CDN。公式排版一次后会缓存进渲染缓存，
平移、缩放与页面缩略图都不会重新排版。语法写错也不会崩，画布上会显示红色的错误提示，
原文始终保存在元素里；普通文本里的 `$` 不会被误判，`价格 $5 与 $6` 仍然是纯文本。
公式是本应用的扩展，Microsoft Whiteboard 打开时会原样显示 LaTeX 源码。

### 选择与编辑

套索选择、矩形框选、点选、按住 `Shift` 加选、八向缩放手柄、旋转手柄、层序调整、锁定与解锁、
对象吸附对齐参考线、墨迹转形状、复制粘贴再制、方向键微移、`Alt` 加方向键旋转、替代文本。

**框选手势**：按下就进入虚线框选流程，拖动过程中实时画出虚线矩形或虚线套索，
同时忽略按下的那个对象；松手时再根据最终区域判定选中了哪些东西。
起点落在已选中的对象上时，这一次是移动；原地点一下等同于点选；拖动手柄不受影响，一按即生效。

**图片等比缩放**：图片与反应无论拖角手柄还是边手柄，都保持长宽比不变。

### 所选操作栏

选中任何对象后，选区下方会浮出一条操作栏：编辑、便签样式、改变颜色、复制到上一页、下一页或
指定页码、复制、再制、删除、置于顶层、置于底层、移到图层最底层。拖动时它会自动隐藏，
不会挡住手势；误关之后可以点工具栏的「操作栏」按钮恢复。操作栏会按所选内容增减按钮，
只选文本框时没有便签样式，只选形状时两个都没有。

- **编辑**：只选中一个文本框或一张便签时出现，点一下直接进入文字编辑，不用再双击。
- **便签样式**：所选里只要有便签就出现，一次调整其中所有便签的圆角、颜色与不透明度，
  一次拖动只记一步撤销。
- **复制到任意页**：把选中的对象按原坐标复制到目标画纸，原页保留，可以撤销。
- **改变颜色**：按所选内容自动切换色板；便签只换色相并保留自身透明度，
  图片与反应不能改色，会给出提示。
- **移到图层最底层**：解决图片盖住批注的问题。

### 删除

`Delete` 或 `Backspace` 删除全部选中对象，墨迹、形状、文本、便签、表格、图片与反应都可以；
工具栏的垃圾桶按钮、「更多」菜单与右键菜单都能触发。删除可以整体撤销，
并恢复原来的层序与选中状态。空白处右键是另一套菜单：粘贴、全选、解锁全部、
在此页之前或之后新建画纸、适应页面宽度、显示整页与清空当前画纸。

### 视图与比例

无限画布、手形移动工具、按住空格拖动、中键拖动、滚轮平移、`Ctrl` 加滚轮以光标为中心缩放、
双指缩放、适应宽度、显示整页、全屏，以及四种背景：无背景、方格、横线与点阵，并可自定画布颜色。

**比例是全局的**：整个白板只有一个缩放比例，在第一页把比例调到 100%，翻到第 50 页、
第 200 页也还是 100%；翻页只改变滚动位置，不改变比例。

**底栏比例可以直接输入**：在右下角的比例框里输入 `137`、`42.5%` 或 `250` 回车即跳到该比例，
留空回车回到 100%，非法输入不生效。新建或打开白板的默认比例是 80%，
可以在设置里改成 50%、80%、100%、125% 或 150%。

### 页面与文件

- **页面**：页面面板每页一张预览图，可以拖拽排序、复制与删除；还可以新建画纸，
  用右下角的页码框跳转，或用 `PageUp`、`PageDown` 翻页。
- **打开页面时的取景**：有内容的 PDF 页按纸面显示，纸面左右居中、顶部贴住窗口顶部。
  整页没有 PDF，或者 PDF 那一页是纯白的，这类页面没有纸面可以取景，改以内容为准，
  把**最左侧内容的最上侧**对到窗口左上角，右边更高的列不会让左上角留出空白；
  内容比窗口宽时多出来的部分往右下延伸，比窗口窄时也不居中。
  空白背景的判断是异步的，打开这类页面时会先按纸面显示，随即自动校正到内容左上角，
  结果按页缓存，回到该页不会再闪。`Ctrl+Shift+0` 的显示整页不受影响。
- **在空白页上粘贴图片**：图片落在页面起点，也就是这页取景的锚点，所以页面从哪儿开始，
  图片就贴在哪儿；页面上已经有内容时，图片仍然贴在正在看的地方。
- **快捷键区分大小写**：小写字母是工具，`N` 是便签；大写字母是独立绑定，`Shift+N` 是新建白板，
  所以不会误触发便签工具。
- **其他**：完整撤销重做，默认 300 步；中文输入法友好的文本编辑；
  工具栏位置可以在底部、顶部、左侧与右侧之间切换。

## 已知限制

- **只支持 `.note` 这种本地格式**。云端 `.whiteboard` 是 OneDrive 的存储形式，不是同一种文件。
- **保存会覆盖你打开的那个 `.note`**。想保留原件请用另存为，快捷键是 `Ctrl+Shift+S`。
- **浏览器不给可写句柄时，保存会退化为下载**：Firefox 与 Safari 没有 File System Access，
  拖进来的文件也只有只读快照，这时 `Ctrl+S` 会下载一份副本并说明原因；
  想原地保存请用 Chrome 或 Edge 打开本机文件。
- 从零新建的白板会把 PDF 内嵌进 `.note`，文件大小与 PDF 相当。
- 撤销历史按操作增量记录，上限 300 步。
- 页面预览按需渲染，只画看得见的那几页；快速滚动很多页时预览会逐个补齐。
- 这是单人本地应用，没有协作、评论、模板与联网图片搜索。
- 荧光笔的半圆端点是本应用的渲染规则，新画的高亮会写一个标记字段；
  原版文件没有这个字段，Microsoft Whiteboard 会按平头显示，其余部分不受影响。
- LaTeX 是本应用的扩展，公式以源码存在元素的文本字段里，Microsoft Whiteboard 打开时会显示
  源码，在本应用里则始终渲染为公式。表格单元格暂不支持公式。
- 缩放比例不写进 `.note`，只在本次会话内全局生效，重新打开白板会回到默认的 80%。
